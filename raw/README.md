# raw/

Your sources, exactly as collected. The assistant reads them and never edits,
renames or deletes them.

- Save web articles as markdown (Obsidian Web Clipper works well), PDFs,
  transcripts, notes, chat exports.
- Images go in `raw/assets/` (in Obsidian: Settings → Files and links →
  Attachment folder path → `raw/assets`).
- Name files `YYYY-MM-DD-short-title.ext` so they sort by date.
- Then run `/ingest` in Claude Code, or say "ingest the new sources".

Anything here is committed to Git. If the repository is public, so is this.
